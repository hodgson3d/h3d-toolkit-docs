# Curve Deform Verts

Quickly deform selected vertices along an editable curve with intuitive viewport controls.

## Usage

1. Enter **Edit Mode** on a mesh.
2. Select the vertices you want to deform.
3. Choose the number of curve points.
4. Click **Deform**.
5. Drag the green control points in the viewport to reshape the selected vertices.

## Modal controls

| Control | Action |
| --- | --- |
| **LMB Drag** | Move a control point |
| **+ / -** | Increase / decrease point count |
| **M** | Toggle Original / Uniform spacing |
| **Delete / X** | Remove the active control point |
| **Enter / Space / RMB** | Confirm |
| **Esc** | Cancel |

The curve and control points remain visible through scene geometry while the modal tool is active.
