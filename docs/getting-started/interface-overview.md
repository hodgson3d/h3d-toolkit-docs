# Interface Overview

H3D Toolkit is organized into focused sections so tools stay easy to find.

## Main sections

- **Object Tools** — object-level utilities and modifier workflows.
- **Modelling Tools** — mesh modelling operations.
- **Curve Tools** — curve-based modelling and deformation tools.
- **Selection Tools** — selection helpers.
- **UV Tools** — UV workflow utilities.
- **Materials** — material-related tools.
