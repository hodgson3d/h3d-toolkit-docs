# Interface Overview

H3D Toolkit is organized into focused sections so tools stay easy to find.

## Main sections

- **Object** — object-level utilities and modifier workflows.
- **Modelling** — mesh modelling operations.
- **Curve** — curve-based modelling and deformation tools.
- **Selection** — selection helpers.
- **UV** — UV workflow utilities.
- **Material** — material-related tools.
