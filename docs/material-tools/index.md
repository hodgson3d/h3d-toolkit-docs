# Material

Utilities for cleaning up materials and material slots.

## Keep Active Material Only

Removes every material from the selected object except the active material.

## Delete Empty Material Slots

Deletes empty material slots.

## Cleanup Duplicates

Inspects materials for identical properties and collapses duplicates down into a single material to reduce clutter in the Blender file.

## Remove Materials + Slots

Removes all materials and material slots.
