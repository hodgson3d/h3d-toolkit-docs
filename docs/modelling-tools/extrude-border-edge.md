# Extrude Border Edge

Extrude selected border edges with an even, controllable offset while supporting planar, folded and rounded geometry.

## Usage

1. Enter **Edit Mode**.
2. Select one or more border edges.
3. Run **Extrude Border Edge**.
4. Adjust **Offset** and **Rotation** in the operator controls.

## Multiple objects

The tool supports multiple mesh objects being edited at the same time. Selected border edges on each object are processed independently.
