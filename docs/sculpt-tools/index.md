# Sculpt

Utilities for working with Multiresolution sculpt workflows.

## Delete Lower

Makes the currently active subdivision level on a Multiresolution modifier the new base level.

Works across multiple selected objects.

## Rebuild Subdivisions

Lets you choose how many subdivision levels to rebuild and run the process across multiple selected meshes.

## Separate By Loose Parts

Separates geometry by loose parts while preserving Multiresolution sculpt data that would otherwise be destroyed by Blender's default separation workflow.

## Conform Shape

Applies **Conform Shape** to all selected Multiresolution modifiers.
