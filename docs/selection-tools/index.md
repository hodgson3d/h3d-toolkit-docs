# Selection Tools

Utilities for finding and selecting objects or mesh components based on structure and properties.

## Select by Vert Count

Selects geometry based on vertex/poly count.

## Select Similar

Select one or more vertices, edges or faces and run **Select Similar** to find other components with matching topology.

This is useful for selecting repeated topological features without manually clicking each one.

## Select Instances

Extends Blender's linked-selection workflow so instances can be selected from multiple object selections rather than only from the active object.

## Select By Modifier Name

Selects geometry based on modifier names.

This is useful for finding objects with a specific named modifier attached.
