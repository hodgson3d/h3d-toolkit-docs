# VSE

Utilities for Blender's Video Sequence Editor.

## Split and Offset

Takes an image sequence, splits each frame, and offsets the resulting strips by a user-defined number of frames.

This is useful for review workflows where rendered assets need to be compared against a plate or scan on every nth frame.
